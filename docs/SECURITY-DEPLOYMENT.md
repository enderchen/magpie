# 安全部署与上线验收

2026-10-09 完成代码及本地生产模式验收。正式域名、部署方式尚未确定，公网环境尚未放行。本地测试结果不能替代下列部署检查。

## 构建与运行

- 使用受支持 LTS 的最新安全补丁版本，推荐 Node 24；最低安装要求为 Node 22.13。Node 20 已结束维护，见 [官方维护状态](https://nodejs.org/en/about/previous-releases)。Docker 构建各阶段使用 `node:24-alpine`。
- 使用锁文件安装。构建阶段运行 `npm ci`、`npm run lint`、`npm test`、`npm run build`；运行环境仅安装 `npm ci --omit=dev`，保留构建好的 `public/dist`。
- 全部依赖 `npm audit` 和生产依赖 `npm audit --omit=dev` 均必须通过。CI 已增加全部依赖检查，并覆盖 Node 22、24；本轮未向远端推送或触发 CI。
- 本地干净生产安装、启动、登录、上传、分享渲染和健康检查已通过；Docker 镜像构建、原生 SQLite 在目标平台的兼容性及基础镜像扫描尚未验证。
- `.dockerignore` 排除本地环境文件、数据库、密钥、备份、恢复暂存及日志。不得把真实 `.env` 或数据目录打入镜像。

开发启动使用 Node 自带的 `--watch`，不再依赖 nodemon；`npm run dev` 和 `./start.sh --dev` 已在隔离副本验证启动及已加载模块修改后的自动重启。该功能自 Node 22 起稳定，见 [官方说明](https://nodejs.org/download/release/v22.13.0/docs/api/cli.html#--watch)。

## 域名、HTTPS 与会话

- `APP_URL` 必须为实际对外 HTTPS 地址。完成 DNS、证书、HTTP 到 HTTPS 跳转及代理配置后，以该地址验证首页、登录、分享、上传和 `/health`。
- 设置 `NODE_ENV=production`、`COOKIE_SECURE=true`，为 `SESSION_SECRET` 使用独立随机密钥。缺失、少于 32 字符或示例密钥会拒绝生产启动。
- `TRUST_PROXY` 默认为关闭。只填写真实可信代理的地址或网段；数字跳数仅适用于所有入口路径都符合该拓扑的情况。不要把不可信客户端声明的代理地址当成真实来源。
- Compose 默认将 8858 绑定到 `127.0.0.1`，供 HTTPS 反向代理访问；实际部署若采用容器内代理，使用容器网络连接。
- 在真实 HTTPS 地址检查 Cookie 的 `Secure`、`HttpOnly`、`SameSite`，验证跨站写请求被拒绝、真实客户 IP 的登录限流有效。
- 多人部署优先使用用户级 API Token；全局 `MCP_TOKEN` 具备对应管理员账户的权限，不应发给普通用户。

## 邮件与第三方登录

- 当前邮件连接校验通过；本轮发信测试使用本地模拟邮件，未向真实接收方发送新邮件。部署后，须按已授权的收件人完成验证码及投递验证。
- 关闭 `ALLOW_REGISTRATION` 后，邮箱与第三方登录均不创建新账户；已有绑定账户仍可登录。邮箱注册开放时须配置 SMTP。
- 仅启用需要的 OAuth 提供方，登记真实域名的回调地址。GitHub、Google、微信的状态、绑定和注册逻辑已用模拟提供方测试；真实提供方回调需在部署环境验证。

## 数据、备份与恢复

- 持久化整个数据目录，至少包含 `database.sqlite`、`uploads/`、`token-key.key`。备份下载包含数据库快照和令牌加密密钥，应存放在受限位置。
- 若配置 `TOKEN_ENCRYPTION_KEY`，须单独保护并保留同一环境密钥；ZIP 不包含环境变量，跨机恢复不能只迁移数据库。
- 导出使用独立 SQLite 快照；备份不包含可复用的登录会话。恢复先在暂存目录校验数据库、表/字段、文件和路径，再更换当前数据；失败时使用导入前备份回退。
- 不兼容版本的备份会被拒绝。跨版本迁移须先在隔离环境验证。
- 备份/恢复会短暂暂停数据请求，等待已有请求结束。长连接或持续上传超过等待时间会返回 503，应结束连接后重试。自动回退失败时保持数据接口暂停，管理员按日志指定的导入前备份处理。
- 在目标环境验证持久化重启、备份落盘、保留策略以及恢复。按实际文件大小、并发与存储规模做负载和磁盘余量测试；本地短时并发通过不能视为容量认证。

## 内容隔离的行为边界

用户 HTML、ZIP 入口及资源通过响应头 CSP sandbox 隔离，即使直接打开链接也不能取得工作台的同源权限。Markdown 只信任仓库模板的脚本哈希。

私有或受保护 ZIP 资源使用文件范围的短期凭证，有效期 5 分钟，不可用于管理接口；注销、改密码、撤销令牌或改变分享授权后失效。长时间停留后新增资源请求可能需要刷新预览。依赖工作台 Cookie 或 localStorage 的用户脚本不会获得这些权限。

## 放行标准

在实际部署平台确认：构建与启动通过、HTTPS 与 Cookie/代理正确、持久化重启与恢复通过、需要的邮件/OAuth 真链路通过、代表性负载与基础镜像检查通过。保留实际版本、检查结果、备份及回退方案，再执行已获授权的上线动作。
