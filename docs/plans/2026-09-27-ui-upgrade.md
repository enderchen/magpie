# Magpie UI 升级与阶段状态

## 已确认范围

以现有新首页为基准，升级本期 Web 页面为浅色 Neo-Brutalist 风格。根地址始终展示官网，工作台使用 /app/。市场、插件、历史稿及用户上传内容的内部样式不在本期改版范围。分阶段验收后继续。

## 阶段

1. 首页替换：实现完成，待用户验收。回退基线 aab54f5。根地址提供新首页，/app/ 提供原应用壳；迁移旧业务 hash 链接、OAuth 与邮箱验证回跳，保留首页动画和试用。
2. 公共样式与账号页：待阶段一验收。统一设计变量、按钮、表单、弹窗和登录注册、验证结果页；本期页面固定浅色。
3. 工作台：待实施。上传、内容库、筛选搜索、分类标签、收藏、分页与批量操作。
4. 预览分享：待实施。工具栏、源码、ZIP 树、版本历史、分享设置及异常状态，不覆盖用户正文。
5. 设置管理：待实施。账号、令牌、AI 接入、用户、数据、用量、反馈。
6. 辅助页面与回归：待实施。政策条款、示例外围界面及全站验收。

## 验证与交付规则

每阶段执行相关功能测试、Lint、完整测试和构建，使用真实浏览器检查关键交互与受影响视口。数据库回归使用隔离数据，不修改现有用户文件。独立提交，阶段验收前不进入下一阶段。本计划不包含生产部署和 npm 发布。
